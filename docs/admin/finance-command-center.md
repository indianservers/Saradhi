# Finance command center

No read/reporting endpoint currently supplies reconciled platform revenue, GMV, fees, settlements, reconciliation exceptions, tax, or payout aggregates. The web apps therefore show no financial values and provide no exports or payout actions.

The backend has sandbox payment/refund and maker-checker refund approval endpoints, but no admin queue/read model for these apps. A finance UI requires ledger-sourced reports, finance-scoped list APIs, export controls, and reconciliation measurements first.
