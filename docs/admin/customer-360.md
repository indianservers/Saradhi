# Customer 360 status

Customer account/profile, order, support, consent, loyalty and referral foundations are spread across existing modules. There is no single Company Admin customer 360 page/API in this release. No broad customer export or import was added.

Any future view must use explicit city/role scope, minimum necessary fields, audited purpose, consent/privacy status and server-side pagination. Do not provide unrestricted impersonation, password import or unverified phone/email login. Current gap remains PARTIAL.
