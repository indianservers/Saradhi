# Dashboard metrics

Current company and city metric cards are real operational counts from the selected authorized city's dispatch and verified fleet endpoints, plus the incident list. They are snapshots refreshed every 30 seconds. The task count sums the four returned active states, and the fleet card sums verified pilot states.

The current API does not provide historical windows, order volume, gross merchandise value, cancellation rate, delivery SLA, payment totals, currency-normalized revenue, or a cross-city aggregate endpoint. Those metrics are intentionally omitted; current counts must not be read as trends or financial totals.
