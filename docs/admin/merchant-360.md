# Merchant 360 status

Merchant organization, brand, branch, catalogue, order, commission, document and settlement data exist across modules, with scoped individual APIs. Company Admin does not yet expose a complete merchant detail workspace or all requested tabs. The new data-operations screen can create pending branches and export authorized branch rows only.

No merchant state changes are exposed through the bulk screen. Use existing domain APIs for authorized individual changes; do not infer approval from import success. Required next work: aggregated resource-scoped read model, document expiry, account manager assignment, sales/acceptance metrics with definitions, complaint/dispute queue and audit timeline.
