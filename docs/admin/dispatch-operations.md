# Dispatch operations

The operations screens show city-scoped unassigned, offered, assigned, and picked-up task counts and a cursor-limited task list. Pilot incidents can be acknowledged and resolved after a required resolution summary. Each action reloads authoritative data and is revalidated by the backend.

Manual assignment/reassignment controls, route sequencing, bulk dispatch actions, and GPS map presentation are not exposed by the present contract. AI recommendations and model registry records do not constitute dispatch execution.
