# Merchant finance and settlements

Merchant settlement screens now show an explicit unavailable state and no sample balances. The shared backend includes finance ledger, journal, refund approval and payout-related foundations, but no authenticated merchant branch/organization settlement summary, merchant statement history or authorized statement download contract was identified for this app.

Do not compute merchant payable from order totals in Flutter or expose banking details through improvised endpoints. A future finance API must return ledger-derived gross, commission, platform fee, merchant-funded discounts, tax/refund deductions, net payable and settlement status with organization/branch permission checks and reconciliation evidence. Banking changes require a separately protected workflow.
