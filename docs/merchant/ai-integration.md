# Merchant AI integration

The existing AI platform and customer recommendation endpoints do not currently supply a merchant-scoped operational copilot contract. No merchant forecast, preparation estimate, inventory risk, branch comparison or insight is shown by this app. This avoids fabricated demand or popularity claims.

Before adding actions, expose organization/branch-authorized, bounded data tools and return model status/provenance/fallback. Restrict the assistant to read-only insights by default; any operational write needs explicit staff permission and confirmation. Price, bank, role and approval changes must remain outside autonomous AI control. Training-data readiness and model evaluation must be documented before showing forecasts.
